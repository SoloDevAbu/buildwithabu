## Why code, and not an editor

A coding agent can't drag clips on a timeline, but it can write files. Remotion lets you describe video as React components, so every scene becomes a file the agent can read, change and render again. That gives you something a timeline doesn't: a note like "move the card up" becomes a precise edit, not a redo.

## The stages that matter

One big prompt falls apart because nothing checks the work between steps. Split it up instead:

1. **Research.** Make the agent open real sources and save them. Anything it can't source gets cut.
2. **Script.** Ask for two different angles, so you are choosing and not just accepting.
3. **Approval.** Stop here. Voice and scenes are expensive to redo, and a script is cheap to change.
4. **Voice and captions.** Generate speech, then time each word to the audio.
5. **Scenes.** Plan them on the real voice timings. Timing a scene to a guess is why cuts feel off.
6. **Review.** Render stills and check them against the platform's no-go zones.
7. **Render.** Output 1080 × 1920 and write the post caption.

## What to give the agent

Agents do best with written rules. Keep a project file that says what good looks like, which components exist, and what never to do. Then write one instruction file per stage, so the agent loads only what it needs for that step.
